App Android para navegación y compra de productos geek, incluyendo catálogo, carrito de compras, lista de deseos y reservas de eventos.


## 🚀 Características principales

- **Autenticación** 
- **Catálogo de productos**
- **Lista de deseos**
- **Carrito**  
- **Gestión de eventos** 
- **Redes sociales**


## 🛠️ Tecnologías

Kotlin, Android Studio 2024, Firebase, Material Design, Gradle, Git


## 📱 Requisitos

- Android Studio 2024.1.2 o dispositivo Android 10(o superior)
- SDK mínimo: Android 10 (API 29)  
- Configuración Firebase (`google-services.json`)  


## ▶️ Instalación

```bash
# Clonar el repositorio
git clone https://github.com/AndresRuggieroGitHub/arcadebits.git
```

- Abrir proyecto desde Android Studio
- Sincronizar Gradle
- Configurar emulador o dispositivo
- Ejecutar app (Run 'app' ▶️)
- Colocar `google-services.json` en `app` y sincronizar


## 💡 Destacados

- Persistencia de sesiones
- Validación de formularios
- Filtrado dinámico de productos
- Integración con Firebase
